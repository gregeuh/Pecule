# P2 — cohérence de présentation

| Point | Cause / constat | Correction et propriétaire |
|---|---|---|
| 3.1 Montants | `money` utilisait déjà Intl et les séparateurs français, mais des signes étaient assemblés dans les composants ; le net positif n’avait pas de signe. Une deuxième instance de formatage existait dans le signal du disponible. | `money(cents, decimals, signed)` centralise signe moins U+2212, groupement U+202F et signe positif des mouvements/nets. Comptes et soldes restent non signés s’ils sont positifs. Aucun montant stocké ni calcul n’est modifié. |
| 3.2 Dates | Les styles de référence appliquent `text-transform:capitalize` aux groupes de dates et aux mois. | Surcharge `none` sur les dates concernées ; les chaînes françaises viennent déjà d’Intl. |
| 3.3 Icônes | Réglages et filtres partageaient Settings2. | Entonnoir `Funnel` réservé au filtre d’opérations. |
| 3.4 Libellés | Un survol persistant sur écran tactile peut donner une teinte d’action au texte d’une opération. | Le libellé reste dans la couleur d’encre, y compris au survol ; les revenus gardent leur couleur sémantique. Le libellé privé cité dans le PDF n’est pas recherché dans les données personnelles. |
| 3.5 Alignement | Outils, recherche et groupes de lignes appliquent leurs propres espacements mobiles. | Une marge commune `--ledger-gutter:16px` possède leurs bords de contenu. Les icônes internes conservent leur place. |
| 3.6 Marque | Chaînes d’interface, titre et manifeste utilisaient PECULE. | Pécule dans les textes, noms accessibles et métadonnées ; `pecule.` reste le logotype. Les identifiants techniques ne changent pas. |
| 3.7 Cases | Le rendu natif sombre manque de bordure visible. | Même input checkbox natif, avec bordure contrastée, coche et état indéterminé dessinés en CSS, focus visible et zone de label de 44 px. |

Les saisies numériques et le CSV conservent leur sérialisation sans symbole monétaire ; les `toFixed` du tracé SVG concernent des coordonnées. Ce ne sont pas des formats d’affichage de monnaie et ils ne doivent pas être remplacés par une devise.

Captures avant/après et journaux dans `outputs/brief-corrections/p2`. Les tests de présentation ajoutés couvrent groupement, signe, zéro, valeurs négatives et affichage arrondi ; les tests financiers existants restent requis.
