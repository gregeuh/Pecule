Les captures 390 px clair/sombre avant et après, métriques et rapports sont dans `outputs/brief-corrections/p1`, ignoré par Git. Le script refuse toute écriture réelle de budget.

Les contrôles de chaque lot comprennent TypeScript, lint, tests unitaires et compilation ; les journaux locaux sont conservés dans les sorties de ce lot. Le clavier iOS physique n’est pas déclaré vérifié.
